# Classic Aqua-style Scrollbars for macOS

This tweak restores the classic Aqua-style scrollbars on macOS. It mimics the look and feel of the old scrollbars found in earlier versions of macOS.

## Installation
1. Download the scrollbars tweak package.
2. Open the package and follow the installation instructions.
3. Restart your macOS system for the changes to take effect.

## Usage
After installation, the scrollbars will revert to the classic Aqua style, making for a nostalgic and visually appealing experience while using macOS. 

## Customization
You can further customize the appearance of the scrollbars by modifying the preferences located in the application settings.

## Troubleshooting
If you encounter any issues:
- Ensure that you have followed the installation instructions carefully.
- Reboot your system after installation.
- Reach out to the support community for assistance.
