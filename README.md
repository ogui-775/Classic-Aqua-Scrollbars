# Classic Aqua-style Scrollbars for macOS

This tweak restores the classic Aqua-style scrollbars on macOS. It mimics the look and feel of the old scrollbars found in earlier versions of macOS.

## Installation
1. Pull a copy of the repo.
2. Build into a .dylib for your arch.
3. Install with ammonia.
# Pre-compiled
1. Download the precompiled binary and move to your tweaks folder. 

## Usage
After installation, the scrollbars will revert to the classic Aqua style, making for a nostalgic and visually appealing experience while using macOS.
